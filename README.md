# nvim-orgmode (read-only mirror)

Read-only mirror of https://github.com/nvim-orgmode/orgmode, synced every 12 hours.

- Upstream branches and tags are mirrored as-is (`master`, etc.). Do not push to them.
- This `sync` branch (the default) only holds the sync workflow.
- Sync workflow needs a `MIRROR_TOKEN` secret (PAT with `repo` + `workflow` scopes).
